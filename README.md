# TutorReminderBot

Telegram-бот для автоматических напоминаний ученикам о занятиях.

### Цель проекта
Разгрузить расписание репетитора и снизить риски отмен или пропусков уроков из-за забывчивости учеников.

### Ключевые функции
* Автоматическая отправка уведомления ученику за 24 часа до занятия.
* Удобная панель для репетитора для ввода расписания уроков.
